# 山野本地记忆 Skill（shanye-memory）

> 换个模型，不用再把自己讲一遍。

## 这是什么

各家 AI 都在做记忆，用得越久越懂你。但它们记住的主要是**你是谁**：说话习惯、偏好。
**你做到哪了**它们带不走：手上的项目到第几步、上周为什么放弃另一个方案、明天要解决什么。这些每天都在变，而且锁在各自家里。

这个 Skill 让 Agent 帮你在自己电脑上维护一套纯文本记录，三句话搞定：

| 你说 | 它做什么 |
|---|---|
| 「记日记」 | 把今天整理成一篇日记和一份每日总结，同时把每个项目的进度更新到最新 |
| 「周回顾」 | 翻最近 7 天，挑出你反复出现的判断和习惯，你点头的才写进档案 |
| 「交接」 | 生成一页纸：你是谁、做到哪了、别怎么做。贴给新模型，它马上能接着干 |

## 它会生成什么

```
你的文件夹/
├── 我是谁.md      # 你怎么想事情，慢慢攒，每条都经你确认
├── 做到哪了.md    # 每个项目的最新进度，每天更新
├── 交接页.md      # 换模型时贴过去的那一页
└── 日记/2026/2026-01/2026-01-15/
    ├── 日记｜2026-01-15.md
    └── 每日总结｜2026-01-15.md
```

全部是普通的 Markdown 文本，任何编辑器都能打开，哪天不用这个 Skill 了，文件照样是你的。

## 目录

```
shanye-memory-skill/
├── SKILL.md              # Agent 读的说明（三个动作、脱敏、边界）
├── templates/
│   ├── 日记模板.md
│   ├── 每日总结模板.md
│   ├── 做到哪了模板.md
│   ├── 我是谁模板.md
│   └── 交接页模板.md
├── README.md
└── LICENSE
```

## 怎么装

- **支持 Skill 目录的 Agent**（如 Claude Code 等支持 `SKILL.md` 的助手）：把整个文件夹放进它的 skills 目录，例如 `~/.claude/skills/shanye-memory/`。
- **不支持 Skill 的 Agent**：把 `SKILL.md` 的正文和几个模板贴进系统提示词或「自定义指令」。
- Agent 需要能**读写本地文件**。

第一次用时告诉它存在哪，例如：「我的记录放在 `D:/我的记录`」。之后每天一句话。

## 用不用 Obsidian 都行

- 不用：就是一个普通文件夹。
- 用：把文件夹放进你的库里。文档之间的 `[[链接]]` 可以直接点，日记会连成一条时间线。建议把「日记」核心插件的日期格式设为 `YYYY-MM-DD`。
- 不想要 `[[链接]]` 写法：告诉 Agent「链接写法用 none」。

## 示例（以下全部为虚构数据）

**每天收工**

> 你：记日记。今天把店里的价目表改完了，跟供应商 L 先生谈了下批货，价格没谈拢明天再说。原来说周六去仓库，改成周日了，因为周六要等货。
>
> Agent：已存：日记/2026/2026-01/2026-01-15/。今天 1 件完成、1 件转明天，进度更新了 2 个项目。

`做到哪了.md` 里对应的一段：

```markdown
## 下批进货
- **目标**：月底前订下批货
- **到哪一步**：和 L 先生谈过一轮，价格没谈拢
- **最近的决定**：去仓库从周六改到周日｜因为：周六要等货（2026-01-15）
- **卡在哪**：价格
- **下一步**：明天再和 L 先生谈一次
```

**每周一次**

> 你：周回顾。
>
> Agent：这周有 2 条反复出现，要不要写进「我是谁」？
> 1. 谈价格前先定好自己的底线（01-12、01-15）
> 2. 不喜欢一次给太多方案，三个以内（01-11、01-13、01-14）
>
> 你：都留。

**换模型那天**

> 你：交接。
>
> Agent：（输出一页交接页，同时存为 `交接页.md`）

把这一页贴给新模型，它会先用五行复述你在做什么、下一步是什么，你确认后再开始。

## 隐私说明

- 所有内容只写到**你自己电脑上的文件夹**，Skill 本身不上传、不发消息。
- 默认 `normal` 脱敏：金额写量级、他人用代称、健康数值只写「已报/未报」；密钥、密码、电话、地址任何情况都不写。
- 可以说「这篇只给自己看，不用脱敏」，日记会按原样写（密钥仍打码）。
- **交接页一定会脱敏**，因为它是要贴到别的 AI 服务里的；末尾会写明略去了哪几类信息。贴之前建议自己再看一眼。
- 你使用的 AI 服务本身会处理对话内容，请按该服务的隐私政策自行判断。
